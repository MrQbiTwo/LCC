# LittleCCompiler release website

Jekyll source for the technical release archive at
[https://mrqbitwo.github.io/LCC/](https://mrqbitwo.github.io/LCC/).

This branch contains the website, report metadata and site tooling only.
Compiler sources are maintained on [`main`](https://github.com/MrQbiTwo/LCC/tree/main).

The current release records are clearly labeled demonstrations with simulated
outcomes. See [site development instructions](site_tools/README.md) to build,
preview and validate the site. GitHub Actions deployment is not configured yet.
